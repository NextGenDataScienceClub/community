# 05: Interactive Resources

These resources are intentionally curated for students who want to practice Git in a low-risk environment before applying the workflow to real repositories.

## Interactive Simulators and Games

### Learn Git Branching
- Link: https://learngitbranching.js.org/
- Use this when you want to practice branching, rebasing, and merge conflicts visually.

### Oh My Git!
- Link: https://ohmygit.org/
- Use this when you want a playful, game-like Git journey that teaches repository concepts through quests and challenges.

### Git Immersion
- Link: https://gitimmersion.com/
- Use this when you want a structured, step-by-step introduction to common Git workflows.

## Interactive GitHub Labs

### GitHub Skills
- Link: https://skills.github.com/
- Use this when you want guided GitHub workflows, from branch creation to pull requests and collaboration.

## Documentation and Guides

### Pro Git Book
- Link: https://git-scm.com/book/en/v2
- Use this as the canonical reference for Git fundamentals, branching, advanced operations, and repository internals.

### Atlassian Git Tutorials
- Link: https://www.atlassian.com/git/tutorials
- Use this when you need a well-structured conceptual walkthrough of pull requests, rebasing, and conflict resolution.

## Emergency and Troubleshooting References

### Dangit, Git!?!
- Link: https://dangitgit.com/
- Use this when you have made a mistake and need a practical, plain-English recovery guide.

### GitHub Education Cheat Sheet (PDF)
- Link: https://education.github.com/git-cheat-sheet-education.pdf
- Use this as a quick reference during labs, PR work, or when you need a compact list of essential commands.

## Suggested Learning Path

1. Start with Learn Git Branching or Oh My Git! to build intuition.
2. Use GitHub Skills to practice PR workflows with a real online environment.
3. Keep Pro Git open as a reference when commands or concepts feel unclear.
4. Use Dangit, Git!?! when a mistake needs a safe recovery procedure.

## Recommended Practice Plan

- 15 minutes: branch and merge simulation
- 15 minutes: commit history exploration
- 15 minutes: conflict resolution challenge
- 15 minutes: pull request and review exercise
- 15 minutes: recap and troubleshooting

This is a good student-friendly cadence for club workshops or self-study sessions.
